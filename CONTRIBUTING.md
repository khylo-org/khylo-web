# Contributing to Khylo Web

Thanks for helping make Khylo better.

- Work on `main`, keep each change small and focused, and describe what it changes for the people who use Khylo.
- Run `npm run build:check` (types) and `npm run lint` before you push. New code should follow the style of the code around it.
- Everything people see is about Khylo: no other project's name in screens, messages, links or file names. The one exception is the licence credit.
- The look is premium and calm: subtle fades, a slight grow on focus. No flashy effects.
- Never commit server data, signing keys, passwords or logins.

Khylo is free software under the GPL. By contributing you agree your changes are licensed the same way.
